## 🎯 QUY ĐỊNH LƯU TRỮ HÌNH VẼ
Thư mục này dùng để lưu trữ toàn bộ file sơ đồ phân tích và thiết kế của các bài LAB (LAB 0 đến LAB 8) theo đúng thông báo của giảng viên:
- **Công cụ:** Draw.io (diagrams.net), PlantUML, StarUML, Visio / UML modeling tools.
- **Yêu cầu:** Giữ nguyên định dạng gốc của công cụ vẽ (như `.drawio`, `.vsdx`, `.asta`, `.puml`, v.v.), không xuất ra dạng hình ảnh đơn thuần.

## 📁 CẤU TRÚC THƯ MỤC THEO BÀI LAB

- `LAB0/`: Minh chứng cài đặt & kiểm tra môi trường (JDK 21, Maven 3.9, Git, Docker, PlantUML).
- `LAB1/`: Các file sơ đồ phân tích Hệ thống Thư viện online & Cửa hàng nước giải khát.
- `LAB2/`: Các file sơ đồ phân tích và thiết kế Hệ thống Quản lý Thư viện.
- `LAB3/`: Các file sơ đồ phân tích và thiết kế Hệ thống Quản lý Khách sạn.
- `LAB4/`: Các file sơ đồ phân tích và thiết kế Hệ thống e-Shopping.
- `LAB5/`: Các file sơ đồ phân tích và thiết kế Hệ thống Quản lý Công ty Du lịch.
- `LAB6/`: Các file sơ đồ phân tích và thiết kế Hệ thống Quản lý Hồ sơ Bệnh án.
- `LAB7/`: Các file sơ đồ phân tích và thiết kế Hệ thống Quản lý Nhân sự (gồm các file PlantUML `.puml`).
- `LAB8/`: Các file sơ đồ phân tích và thiết kế Hệ thống Quản lý Cửa hàng Nước Giải Khát.
